# zrudnick.github.io

Source for my personal portfolio site, published via GitHub Pages at
https://zrudnick.github.io.

## Editing

- `index.html` — all page content (hero, about, projects, contact). Look for `TODO` comments marking placeholder text.
- `style.css` — styling. Colors are defined as CSS variables at the top (light/dark mode supported automatically).

## Publishing

This repo must be named exactly `zrudnick.github.io` and pushed to GitHub under the
`zrudnick` account. GitHub Pages serves it automatically from the `main` branch root —
no build step, no `/docs` setup needed.
